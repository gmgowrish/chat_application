      How your privacy works
      
				
			
      
			
        
				
      • End-to-end encrypted. Messages, photos and files are encrypted in your browser (ECDH P-256 + AES-256-GCM). The server only relays ciphertext.
        • 
				
      • Verify people. Tap someone in the list and compare the emoji. Verified people get a green shield, and you'll be warned if their key ever changes.
        • 
				
      • Files disappear. Encrypted files are deleted from the server after one hour.
        • 
				
      • What the server keeps. For security and abuse prevention it logs connection metadata (IP address, browser, times, message counts) for 30 days. Never message content.
